## Agent skills

### Issue tracker

Issues live in GitHub Issues for `iamivanhx/macos-setup` (via the `gh` CLI); specs are written to `docs/specs/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to labels of the same name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
